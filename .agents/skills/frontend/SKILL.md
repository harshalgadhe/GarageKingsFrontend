# frontend

This skill card enforces frontend coding standards.

---

## 1. UI styling & Vanilla CSS
- Use Vanilla CSS for styles; avoid adding Tailwind packages unless requested.
- Maintain CSS variables inside `index.css` for primary/secondary colors and spacing tokens.

---

## 2. Component Organization & Props
- Keep UI components modular, separating layout screens from local form logic.
- Verify user credentials using session cookie validations before allowing access to administrative dashboards.

---

## 3. Responsive Layouts
- Design layouts using touch-friendly tap scales. Ensure views fit gracefully on mobile devices.
